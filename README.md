# Menu Page

A clean and responsive **digital menu webpage** for displaying food items and their details.

## ✨ Features

* Display food items
* Food categories
* Item names and prices
* Clean and attractive layout
* Responsive design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **web design, responsive layouts, and frontend development**.
